# XibToSwiftUI — Native macOS Zip/XIB → SwiftUI Converter

Upload a `.zip` archive of `.xib` files (or individual `.xib` files) and generate clean, idiomatic SwiftUI views head-to-head.

## Features
- Native macOS SwiftUI application + `XibToSwiftUI.xcodeproj`
- Drag-and-drop or file-picker upload for `.zip` and `.xib` files
- Pure Foundation `XMLParser` XIB AST + head-to-head SwiftUI code generator
- Side-by-side XIB structure & generated SwiftUI preview with 1-click Copy & Export `.swift`
